      For the engineers

      Behind the code

      Janitor in the daytime, junior software engineer by nighttime. I built and still run this entire site myself — no agency, no template. It's a plain static page (no framework) backed by a handful of serverless functions and a Postgres database, and the source is public if you want to poke around.

      Diagram renders when you expand this panel.

      The frontend is deliberately boring: hand-written HTML/CSS/JS, no build step, no bundler. Every chart on this page — the weigh-ins, the seizure-frequency bars — is plain SVG built and animated by app.js, with no charting library. The backend is a set of small Vercel serverless functions in api/, each one reading or writing a Neon Postgres database (training runs, weigh-ins, milestones, fundraising totals, comments, race-day GPS).

      Every change ships the same way: a feature branch, a pull request with its own live Vercel preview URL, then a squash merge to main that Vercel auto-deploys straight to this domain — usually within a minute or two of merging.
