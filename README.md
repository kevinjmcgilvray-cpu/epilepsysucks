# Epilepsy Sucks

Kevin’s story site for the LA Marathon / CURE Epilepsy — hosted at [epilepsysucks.org](https://epilepsysucks.org).

## Local

Open `index.html` in a browser, or from this folder:

```bash
open index.html
```

## Deploy (GitHub → Vercel)

1. Push this repo to GitHub.
2. In [vercel.com](https://vercel.com): **Add New Project** → import the GitHub repo.
3. Framework preset: **Other** (static). Root directory: `.`
4. Deploy, then add domain `epilepsysucks.org` under **Project → Settings → Domains**.
5. At your domain registrar, point DNS to Vercel’s records (Vercel shows the exact values).
